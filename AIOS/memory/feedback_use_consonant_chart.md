Before proposing or naming an MS root, read the "Consonant correspondences" table in `Anthropology.md` (PS → Hebrew, Israeli, Aramaic, MSA, MS) and derive each radical from the PS consonant, not from the Arabic or Hebrew spelling.

**Why:** the user (2026-11-18) caught that I called the "laugh" root "Ḍ-Ḥ-K" from the Arabic spelling; MS has no ḍ, and Arabic ض is PS *ṣ́ → MS ṣ ܨ, so the root is ܨ-ܚ-ܟ (Ṣ-Ḥ-K). The chart is the vault's own derivation, made on purpose.

**How to apply:** for every Swadesh gap or new coinage, map each cognate radical back to its PS consonant via the chart, then to the MS letter, and say where a source is irregular (Hebrew q for k, Syriac g for ṣ́ in this root). Put the PS form in the entry. See [[project-middle-semitic-lexicon-conventions]].
