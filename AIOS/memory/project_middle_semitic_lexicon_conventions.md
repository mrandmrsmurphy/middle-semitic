# Middle Semitic lexicon conventions

**Why:** Middle Semitic's lexicon moved into the vault (imported from the Google Sheet); a future session should follow the established pattern rather than re-derive it. Model: the Interslavic lexicon conventions in the UL vault.

**How to apply:**

- One file per word in `Lexicon/`, named and titled by the **unvocalized Syriac spelling**. Homographs: the first coinage keeps the bare spelling, later ones take a numeric suffix — `ܒܢܝ.md` (banê, he built) vs `ܒܢܝ 2.md` (binî, on me). Never mix RTL script and Latin parentheses in a filename — it renders garbled in Obsidian (user, 2026-10-24). `Lexicon.md` holds the entry format and an index line per entry — add one for every new file.
- Entry rows (omit any that don't apply): Full (vocalized), Latin, Root, Part of speech, Gender, Gloss, Hebrew, Arabic, Aramaic, Proto-Semitic (starred; "(hypo)" = hypothetical, "invented" = no PS basis), Notes, Swadesh №. Verbs are cited as 3ms perfect ("he ate").
- YAML frontmatter (user, 2026-10-28 — the reason for the spin-out): entries carry their data as Obsidian properties so cognates beyond Hebrew/Arabic/Aramaic are recordable (ugaritic, akkadian, geez, phoenician... — any tradition gets its own lowercase key, added when evidence exists). Core keys: root, pos, gender, gloss, hebrew, arabic, aramaic, proto-semitic (quoted — it starts with *), swadesh. The visible table stays until a bulk migration is approved. Documented in `Lexicon.md`; pilot entries: ܡܠܟܐ, ܣܡܥ, ܛܘܠܐ, ܥܒܝ 2, ܐܚܪܐ.
- The lexicon was imported from a Google Sheet (347 entries, 2026-10-24). The sheet is RETIRED (user, 2026-10-29): `Lexicon/` is the source record, the sheet is no longer linked from the vault, and it need not be checked before creating entries. (Historical re-pull, only if ever needed for archaeology: `curl -sL '[retired spreadsheet link removed]'`.)
- Data quirks carried over from the sheet: Hebrew `-->` means "see Notes"; ø in a cognate column means no cognate; SwN tags in Notes became Swadesh rows (8 entries: Sw11–13, 22–26).
- Sheet POS is mostly empty for content words (implied by gloss form); noun-m/noun-f were split into Part of speech + Gender rows, v.intr/v.trans/v.stat expanded.
- `Swadesh.md` is the full 207-item comparative page (columns: №, English, MSA, Hebrew, Syriac, Egyptian, Palestinian, MS; romanizations omitted for width — the MS romanization lives on each lexicon page). MS cells are lexicon links; every form used on the page carries a Swadesh № row in its file.
- Reconciliation rule: when the Google Sheet and the old wiki Swadesh table disagree, **the sheet wins** (it is newer); divergences go to the user, not onto the page. Before creating any lexicon file, check the existing `Lexicon/` first — a bulk creation once overwrote six existing entries (restored from the sheet).
- Open questions for the user (from the 2026-10-24 reconciliation): citation form — the paste uses the absolute state (ܫܡܫ, ܟܘܟܒ, ܡܛܪ...) while the sheet uses the emphatic -â state (ܫܡܣܐ, ܟܘܟܒܐ, ܡܛܪܐ...), page currently shows the sheet forms; suspected typo ܠܒܕܐ (kabdâ, liver — spelled with ܠ not ܟ); supplementary items why/how many/which lack script spellings (lemad, kâm, 'ehi). RESOLVED (user, 2026-10-28): ܩܠܠܐ qallâ IS 'few' (Swadesh № 20; cognates קַל / قَلِيل / ܩܰܠܝܠ) — and № 21 'other' was then coined on ʾ-Ḥ-R as expected: ܐܚܪܐ ʾaḥêrâ (Hebrew-shaped, keeping ḥ as an onset).
- Swadesh coverage: 128/207 MS cells filled (2026-10-28). Remaining gaps (79) are mostly basic verbs (drink, sleep, give, say, come, sit, stand, walk, kill, swim, bite, burn, hit, cut...), adjectives (red, cold, full, new, round, dry...), some body/nature words (neck, back, egg, feather, leaf, bark, louse, sand, cloud, smoke), and because. Root reservations (user): Q-T-N is saved for 'slender' (NOT 'small' — too Northwest-Semitic; 'small/young/minor' is Ṣ-ʿ-R, adjective ܨܥܝܪܐ ṣaʿîrâ); ʾ-R-K documented but wordless ('long' is ܛܘܠܐ ṭôlâ). Reserved/wordless roots get a root page with a note and a "— 0" line in the Roots index. A 2026-10-28 pass filled 16 cells whose entries already existed but had never been linked (wife, animal, fat, suck, blow/breathe, see, hear, know, think, dig, tie, sing, ash, in, with) — when filling new cells, check the lexicon for an existing entry first, and every form used on the page carries a Swadesh № row in its file.

- Noun paradigms (user, 2026-10-27): per-noun pages get a Forms chart (regular/construct x singular/plural; NO dual except body parts, glasses, pants) plus a pronominal-suffix table. Suffixes attach to the CONSTRUCT state with nothing dropped (malak-, malkî-, malkat-, malkû-); plural suffixes are -nû -kûm -hûm with the waw (ܢܘ ܟܘܡ ܗܘܡ). Gemination uses Arabic shadda; a doubled letter marks suffixation. Spelling must be readable without vowels. The construct is an archaism kept on these words because of ancient texts (cf. Hebrew avinu malkeinu). Models: `Lexicon/ܡܠܟܐ.md` (masculine), `Lexicon/ܡܠܟܬܐ.md` (true feminine).

- Roots (user, 2026-10-27): roots are productive, so `Roots/` has one file per root, named by the hyphenated Syriac root (e.g. `ܡ-ܠ-ܟ.md`), listing the lexicon words built on it (king, queen, 'he reigned'), plus `Roots.md` as the index. Generated from the Root rows of the lexicon files (271 roots; the three single-letter particle 'roots' ܒ ܘ ܠ skipped). Regenerate or hand-add a root file when a new word with a new root is coined. Beware: Obsidian reformats lexicon tables with padded columns, so any script reading the rows must tolerate extra spaces.

- Root links (user, 2026-10-27): each lexicon entry's Root row links to its root page as `[[Roots/X\|X]]` (escaped pipe, table cell); the Roots index shows a romanization after each root (ʾ-B-B style). New entries should follow both. Fixed ܐ-ܣ-ܥ → ܐ-ܣ-ܪ.
- Not every noun gets a suffix table (user, 2026-10-27): omit it where the word would not naturally take a possessive; kept on kin terms, God, king, and ܐܪܨܐ in the sense "country". The Gloss of ܐܪܨܐ is "earth, land, country".
- Masculine-with-feminine-plural nouns (father, name, house) are Hebrew-only; in MS they are plain masculine (user, 2026-10-27). Do not use that as a crypto-feminine criterion.
- Conjugated prepositions (2026-10-27): the 64 fused forms (ܦܢܝ ...) are lexicon entries with a Components row; ܒܢܝ 2 = "on me" (homograph of the verb ܒܢܝ).
- Verbs (user, 2026-10-27): imperative = 2nd-person non-past minus prefix (mlak!, mlakî!, mlaknâ!), ALWAYS written with an exclamation mark (m sg is spelled like the 3m past). Passive = vowel after the first consonant becomes long û (mûlak, yûmlak), rest follows the active. Model page: `Lexicon/ܡܠܟ.md`.
- Passive participle/infinitive (user, 2026-10-27): ma-/la- prefixes leave no vowel after C1, so the SECOND vowel becomes û: mamlûk-, lamlûk (active mamlak-, lamlak). Imperative has no passive.
- Statives (user, 2026-10-27): the test is TRANSITIVITY, not the English gloss — a transitive verb is not stative (رحم 'have mercy upon' → ܪܚܡ raḥam, active). Check this before respelling any "he was ..." verb to î.
- Derivation: the suffix -ân (ܐܢ) is productive and makes an ADJECTIVE ("marked by X"), which can be used substantively: ܫܘܟܪܢ, ܒܬܘܠܐܢ, ܪܒܐܢ, ḥaṭiyânâ 'sinner'. Entry `Lexicon/-ܐܢ.md`.
- Phonotactics (user, 2026-10-28): only CV and CVC syllables (no clusters); schwa is a marginal sixth vowel, only in clitics' fast speech and in imperatives (məlak!, stress on the 2nd syllable). Check every new form against this. The *aw* → *ô* contraction is absolute (user, 2026-10-28, ruling on №28 'long'): no word contains an *aw* sequence, so even modern Arabic ṭawīl surfaces as ṭôlâ (ܛܘܠܐ, root ܛ-ܘ-ܠ) — same as yômâ and ṭôvâ. Also ruled (user): 'long' is NOT coined from ʾ-R-K (\*ʾarik-, Hebrew אָרֹךְ, Syriac ܐܪܝܟܐ) because Arabic keeps it only for 'long of time'; the root is documented at `Roots/ܐ-ܪ-ܟ.md` with no coinages.
- Derivation (user, 2026-10-28): suffix -ûtâ (ܘܬܐ) makes feminine abstract nouns (baʿlûtâ 'ownership' from baʿlâ); the nouns are true feminine, with hiatus deletion after the û (pl baʿlût). Entry `Lexicon/-ܘܬܐ.md`.
- Stress (user, 2026-10-28): predictable, counted over the whole word (proclitics excluded): a closed (CVC) final syllable takes the stress, otherwise the penult; schwa is never stressed (stress moves right); one-syllable words are unmarked. A compromise of Aramaic (penult), Hebrew (ultima) and Arabic (weight). Romanization: Latin rows of NEW lexical entries show syllable dots and `ˈ` before the stressed syllable (ˈmal.kâ, ma.ˈlak); paradigm cells are not marked; the generator scripts strip `ˈ` and dots (stem_of). The legacy apostrophe stress marks from the Google Sheet collided with ʾ and were normalized away; existing rows have not been retrofitted. Phonology has a ## Stress section; the matrix cell reads `weight`.
