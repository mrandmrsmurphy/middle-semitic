Written into `Design Philosophy.md` ("Choosing between Hebrew and Arabic"). Steps: (1) broadest root/PS first; (2) vote by branch (NW Semitic = one, Arabic = one, Akkadian and Ge'ez one each); (3) outgroups break ties; (4) else tests in order: everyday register, chart-clean, vault family, neutrality, Hebrew slight weight, modern language-count majority last; (5) split senses between the roots where possible; (6) Notes sentence "Branch vote: NW (…) X; Arabic Y; outgroup Z; ruling by …".

**Why:** Hebrew and Aramaic agreeing while Arabic differs is extremely common (user's observation); the old language-count rule let the three Arabic columns outvote the pair. First case: №127 fall (ܢܦܠ vs ܘܩܥ). Akkadian/Ge'ez checks are usually from memory, so mark them unverified.
**How to apply:** run it on every Hebrew/Arabic split; see [[feedback-use-consonant-chart]].
