| Notes | All three sources share the word: the third radical is Proto-Semitic \*ḍ, which gives Arabic ض (bayḍa), Hebrew צ (bêṣâ) and Aramaic ع (bêʿṯā) — the same correspondence as "earth" (ʾarḍ / ʾéreṣ / ʾarʿā, MS [[Lexicon/ܐܪܨܐ\|ܐܪܨܐ]]). MS contracts the diphthong (ay → ê), as Hebrew does; the Levantine and Hijazi dialects pronounce it the same way (bēḍa). Possibly named from whiteness — the same root as Arabic أَبْيَض "white" — so the root is a candidate for Swadesh № 175. Arabic also reads the word as "testicle; helmet; main part", Syriac as "skull, arch". Ugaritic and Proto-Semitic not checked. |

## Forms

True feminine declension (the *t* of the stem shows in the inflected forms, as in Hebrew בֵּיצַת־). There is no dual: the dual is frozen and only body parts, glasses and pants have one. The construct state is frozen and an archaism. See [[Morphophonology]].
