| Notes | The abstract of the adjective [[Lexicon/ܒܗܝܪܐ\|ܒܗܝܪܐ]] "bright" with the productive -ûtâ (see [[Lexicon/-ܘܬܐ\|-ܘܬܐ]]), as Hebrew בְּהִירוּת "brightness, clarity" is built on בָּהִיר. Arabic has no quality noun from this root in common use (the maṣdar of بَهَرَ is بُهُور "dazzling"). Syriac ܒܗܘܪܐ "brightness" is the same root on the qəṭôlā pattern (recalled, unverified). With the clitic *bi-* it is the manner adverb *bi-bahîrûtâ* "brightly" — see [[Morphosyntax#Adverbials]]. |

## Forms

True feminine declension. There is no dual: the dual is frozen and only body parts, glasses and pants have one. The construct state is frozen and an archaism. See [[Morphophonology]]. The forms are built on the stem in the Latin row above.
