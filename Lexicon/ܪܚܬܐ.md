## Forms

True feminine declension. The dual is frozen and only body parts, glasses and pants have one; *palm* is a body part, so it has a dual, built on the feminine stem with the dual ending *-îm* (*raḥatîm*). The construct state is frozen and an archaism. See [[Morphophonology]]. The forms are built on the stem in the Latin row above.
