# Lexicon

> Parent: [[Middle Semitic]] · Basic list: [[Swadesh]] · Sounds: [[Phonology]] · Script: [[Orthography]]

Dictionary of Middle Semitic words, one file per word, each derived from its Proto-Semitic source with cognate evidence (see [[Anthropology]]). The file name and title are the Syriac spelling (unvocalized); the romanization is a row in the entry. Homographs share the bare spelling for the first coinage; later ones take a numeric suffix, e.g. `ܒܢܝ.md` (banê, he built) vs `ܒܢܝ 2.md` (binî, on me).

This lexicon is the source record; new words are coined here, one file per word.

## Entry format

Title is the Syriac spelling, then YAML frontmatter carrying the entry's queryable data, then the visible table.

The frontmatter makes every tradition its own property, so cognates beyond the big three (Ugaritic, Akkadian, Geʿez, Phoenician, MSA vs the dialects…) belong here — add a property whenever evidence exists, omit it when it doesn't:

```yaml
---
root: ܡ-ܠ-ܟ
pos: noun
gender: masculine
gloss: king
hebrew: מֶלֶךְ
arabic: مَلِك
aramaic: ܡܰܠܟܴ݁ܐ
ugaritic: mlk
akkadian: malku(m)
proto-semitic: "*malk-"
swadesh: 100
---
```

Core properties: `latin` (romanization), `root`, `pos`, `gender` (nouns), `gloss` (verbs cited as 3ms perfect, "he ate"), `hebrew`, `arabic`, `aramaic`, `proto-semitic` (quoted, since it starts with `*`; suffix `(hypo)` = hypothetical, `invented` = no PS basis), `swadesh` (№, if any), `date-last-perfect` (the date the entry was last brought to its final form). Cognate properties are open-ended: any tradition gets its own lowercase key. **A missing property means not checked; `none` means checked and confirmed absent** (`ugaritic: none` = someone looked and found no cognate, no `ugaritic` key = no one has looked). Every entry carries frontmatter, derived from its table (a `ø` cell becomes `none`; a `-->` cell is left out); the visible table stays. `AIOS/scripts/ms_frontmatter.py` fills any missing keys, and the build scripts call it after they change an entry.

The table rows (omit a row that doesn't apply):

| Row | Content |
| --- | --- |

| Root | Triconsonantal root (function words have none) |
| Part of speech | |
